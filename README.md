# Fancy cow map: Well-dressed farm animals of Tyrol spotting guide

An interactive spotting guide and web application showcasing traditional cattle, sheep, and stallion drives (*Almabtriebe*) across Tyrol, Austria for the 2026 autumn season.

## Data Source
Event dates and locations are compiled from published tourist board schedules and regional media ([Allgäuer Zeitung](https://www.allgaeuer-zeitung.de)). Dates and celebrations are subject to local alpine weather conditions and pasture timing.
